Lawrence VPA Map About Methodology Data Findings FAQ

Methodology

Plain arithmetic on public files. Every dollar and acre on the map can be traced to a county or GIS field.

Value per acre

value_per_acre = RP_AprTot ÷ acres

RP_AprTot is total appraised value (land + improvements) from the Douglas County Appraiser 2026 file. The county file does not break out land vs. improvements separately, so this map uses the total only.

Acres

  1. Prefer county vproplevel_TotalAcres when it is > 0.
  2. If county acres are 0 or missing, fall back to the parcel-layer acreage (Douglas County Tax_Parcel / geometry).
  3. 868 matched parcels used that map fallback; none were left without a usable acreage for $/acre.

Joining parcels

County PropertyNumber is matched to the map parcel ID (PID style, e.g. 023-017-35-0-00-00-001.00-0). Exact string match.

  • 27,834 / 27,842 map parcels matched (99.97%).
  • 8 map parcels had no row in the 2026 Appraiser file (shown without values).
  • The county workbook has 41,996 rows countywide; the map is limited to Lawrence parcel polygons.

3D height

Extrusion height is proportional to value per acre (or total value / acres in other views), then clamped at the 99.5th percentile so outliers stay in view. At the default 1.0× slider, the capped maximum is about 1,400 meters of extrusion. Legend colors still use uncapped true values; the legend notes the height cap.

What we do not do

  • No owner names, mailing addresses, or other PII from the appraisal roll.
  • No synthetic “DEMO” values — the map uses the 2026 Appraiser file received via KORA.
  • No mill-levy / tax-revenue layer yet (rates not in this release).
