What this map shows

A 3D map of Lawrence, Kansas, where each parcel is colored and extruded by appraised value per acre — total 2026 county appraised value divided by lot acres. Taller, warmer columns return more value per acre of land.

Value per acre is a simple productivity measure used in Strong Towns–style land analysis: it asks how much taxable/appraised wealth sits on each acre, so compact downtown lots can be compared fairly with large-lot commercial or residential land. This site is a civic visualization for Lawrence using public county appraisal data. It is not a tax bill calculator and is not affiliated with Urban3, Pracre, or Strong Towns.

How to read the map

  • Color follows true value per acre (legend quantiles).
  • Height uses the same values but is capped at the 99.5th percentile so a few extreme parcels do not blow the 3D view off-screen.
  • Click a parcel for appraised total, $/acre, class, acres, and situs (no owner names).
  • Other views show parcel acres, zoning, ACS median home value, census density, and building footprints.

Rotate and explore

On desktop: right-drag or Ctrl/Shift+left-drag to rotate/tilt; Q/E or Shift+←/→ to yaw; use the on-screen rotate buttons or the compass to reset north. On mobile, two-finger rotate still works.
